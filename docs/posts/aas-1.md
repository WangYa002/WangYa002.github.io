# AAS项目介绍：企业级身份认证系统

## 项目背景

AAS（Authentication & Authorization System）是我参与开发的一套企业级身份认证与授权系统，为公司内部多个业务系统提供统一的安全认证服务。

## 技术栈

- **后端**：Go + gRPC
- **数据库**：PostgreSQL + Redis
- **认证协议**：OAuth2.0 + SAML2.0
- **架构**：微服务 + Kubernetes

## 核心功能

1. **用户管理**：注册、登录、找回密码
2. **多因素认证**：短信、邮件、TOTP
3. **单点登录**：多系统统一登录体验
4. **权限控制**：RBAC + ABAC
5. **审计日志**：完整操作记录

## 项目挑战

### 高并发场景

系统日活用户超过10万，高峰期QPS达5000+，通过以下方案优化：

- Redis集群缓存会话
- 数据库读写分离
- 请求合并减少DB压力

### 安全加固

- 全链路HTTPS加密
- Token动态刷新
- 防CSRF攻击机制

## 个人贡献

- 参与核心认证模块开发
- 设计并实现Token刷新机制
- 编写自动化测试，覆盖率80%+
