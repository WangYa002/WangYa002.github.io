# 两数之和：算法入门第一题

## 题目描述

给定一个整数数组 `nums` 和目标值 `target`，找出数组中两数之和为目标值的下标。

## 解法一：暴力枚举

```javascript
function twoSum(nums, target) {
  for (let i = 0; i < nums.length; i++) {
    for (let j = i + 1; j < nums.length; j++) {
      if (nums[i] + nums[j] === target) {
        return [i, j]
      }
    }
  }
}
```

**时间复杂度**：O(n²)

## 解法二：哈希表

```javascript
function twoSum(nums, target) {
  const map = new Map()
  for (let i = 0; i < nums.length; i++) {
    const complement = target - nums[i]
    if (map.has(complement)) {
      return [map.get(complement), i]
    }
    map.set(nums[i], i)
  }
}
```

**时间复杂度**：O(n)
**空间复杂度**：O(n)

## 思路总结

1. 暴力解法：双重循环，简单直接
2. 哈希表：用空间换时间，一遍遍历搞定
3. 关键点：需要记录已遍历元素及其下标
