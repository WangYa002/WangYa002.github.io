# 两数之和：算法入门第一题（C++ 解法）

> LeetCode 第 1 题（简单）。虽然是简单题，但哈希表解法是后续三数之和、四数之和等中等题的基础，必须吃透。

## 题目描述

给定一个整数数组 `nums` 和目标值 `target`，找出数组中和为 `target` 的两个元素的下标。假设每个输入只有一组答案，且同一元素不能重复使用。

**示例**：

```
输入：nums = [2, 7, 11, 15], target = 9
输出：[0, 1]
解释：nums[0] + nums[1] == 9
```

## 解法一：暴力枚举

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }
        return {};  // 题目保证有解，不会执行
    }
};
```

**复杂度**：

- 时间：O(n²)
- 空间：O(1)

**优点**：实现简单，无额外空间。

**缺点**：大数据集超时（n > 10⁴ 时明显）。

## 解法二：哈希表（推荐）

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> seen;  // 值 → 下标
        for (int i = 0; i < nums.size(); ++i) {
            int complement = target - nums[i];
            if (seen.count(complement)) {
                return {seen[complement], i};
            }
            seen[nums[i]] = i;
        }
        return {};
    }
};
```

**复杂度**：

- 时间：O(n)
- 空间：O(n)

**核心思路**：用空间换时间。遍历到 `nums[i]` 时，已经把之前的元素放进哈希表，O(1) 查找 `target - nums[i]` 是否出现过。

## STL 容器选型

### 为什么用 `unordered_map` 而不是 `map`

| 容器 | 底层 | 查找 | 备注 |
| --- | --- | --- | --- |
| `unordered_map` | 哈希表 | 平均 O(1) | 本题首选 |
| `map` | 红黑树 | O(log n) | 需要有序时用 |

本题不需要有序遍历，`unordered_map` 平均 O(1) 查找更快。

### `count` vs `find`

```cpp
// 方式 1：count + operator[]
if (seen.count(complement)) {
    auto v = seen[complement];  // 第二次哈希查找
}

// 方式 2：find（推荐）
auto it = seen.find(complement);
if (it != seen.end()) {
    auto v = it->second;  // 复用迭代器
}
```

`find` 只哈希一次，性能略优。但 LeetCode 简单题差异不明显，两种都接受。

## 常见陷阱

### 1. 同一元素使用两次

```cpp
// ❌ 错误：先全部放入哈希表，再遍历查找
for (int i = 0; i < n; ++i) seen[nums[i]] = i;
for (int i = 0; i < n; ++i) {
    int complement = target - nums[i];
    if (seen.count(complement)) {
        return {i, seen[complement]};  // 当 nums[i] = target/2 时，会返回 {i, i}
    }
}

// ✅ 正确：边遍历边查
for (int i = 0; i < n; ++i) {
    int complement = target - nums[i];
    if (seen.count(complement)) {
        return {seen[complement], i};
    }
    seen[nums[i]] = i;
}
```

### 2. 返回下标 vs 返回值

本题要求返回**下标**，所以不能先排序（排序后下标丢失）。如果改成"返回值"，可以先排序再用双指针（见三数之和）。

## 拓展：返回所有不重复的数对

如果题目改成"返回所有不重复的 `nums[i] + nums[j] == target` 数对"，需要：

1. 排序 + 双指针避免重复
2. 或者哈希表 + set 去重

参考 LeetCode 第 15 题（三数之和）的去重逻辑。

## 总结

| 解法 | 时间 | 空间 | 何时用 |
| --- | --- | --- | --- |
| 暴力枚举 | O(n²) | O(1) | n < 1000 |
| 哈希表 | O(n) | O(n) | 通用，n 任意 |
| 排序 + 双指针 | O(n log n) | O(1) | 需要返回值（不要下标）时 |
